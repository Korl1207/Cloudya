# Клиент распределённого хранилища

Кроссплатформенное приложение на C++ и Qt 6 для синхронизации файлов между собственными устройствами. Цель проекта - дать пользователю доступ к одним и тем же файлам без обязательной учётной записи и без хранения данных у стороннего облачного провайдера.

## Как это должно работать

Каждое подключённое устройство хранит локальную копию выбранных папок. Изменения можно делать без сети. Когда два устройства становятся доступны друг другу, они обмениваются сведениями об изменениях и передают недостающие файлы. Для такой схемы постоянно работающий центральный сервер не требуется.

Если устройства редко находятся в сети одновременно, пользователь сможет добавить постоянно включённый узел: домашний компьютер или собственный VPS. Он будет хранить копию данных и синхронизироваться с остальными устройствами на тех же принципах, а не выступать обязательным «главным» сервером. Развертывание такого узла должно оставаться выбором пользователя.

Если один файл изменён на нескольких устройствах до синхронизации, приложение должно сохранять обе версии и сообщать о конфликте, чтобы не потерять данные. Правила удаления файлов, хранения предыдущих версий и защиты соединения ещё предстоит определить.

## Планируемые возможности

- Выбор папок для синхронизации и добавление доверенных устройств.
- Работа с локальными файлами без подключения к сети.
- Синхронизация между устройствами при появлении соединения.
- Необязательный постоянно включённый узел на собственном оборудовании или VPS.
- Отображение состояния синхронизации и конфликтующих изменений.

## Требования

- Компилятор с поддержкой C++17
- CMake 3.16 или новее
- Qt 6 с модулем Widgets

## Сборка

```sh
cmake -S . -B build
cmake --build build
```

## Структура

- `src/` - исходный код приложения и главного окна
- `data/` - каталог ресурсов приложения
- `CMakeLists.txt` - конфигурация сборки

## Состояние проекта

Создан каркас окна, настроена сборка через CMake и GitHub Actions для Linux и Windows. Сетевое соединение, хранение метаданных и синхронизация файлов ещё не реализованы.
